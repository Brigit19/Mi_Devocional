# 🌷 Mi Devocional

**App de seguimiento de devocionales para Casa Apostólica Belén**

## 📱 Características

✅ **Panel de Señoritas**
- Ver devocionales de ayer y hoy
- Subir hasta 5 fotos de evidencia
- Editar evidencias subidas
- Ver racha de días consecutivos
- Ver porcentaje mensual
- Historial completo

✅ **Panel de Líder (5 Tabs)**
- **Hoy**: Ver quién subió su evidencia
- **Resumen**: Estadísticas mensuales
- **Devocionales**: Subir devocionales diarios
- **Señoritas**: Ver progreso de todas (36)
- **Configuración**: Cambiar PIN

✅ **Características Globales**
- Dark mode (☀️/🌙)
- Banner de actualización automático
- Instalable como app (PWA)
- Funciona sin internet (offline)
- Rápido (3-5 segundos)
- 36 Señoritas
- Firebase Firestore para datos

## 🚀 Instalación

1. Abre el navegador
2. Entra a: https://brigit19.github.io/Mi_Devocional/
3. Presiona ⬆️ (compartir)
4. Elige "Agregar a pantalla de inicio"
5. ¡Listo! Ya está descargada como app
